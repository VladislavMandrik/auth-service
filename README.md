# Auth Service

Реактивный сервис аутентификации и управления пользователями на Spring Boot + WebFlux с JWT-авторизацией.

## Стек технологий

| Категория        | Технология                          |
|------------------|-------------------------------------|
| Язык             | Java 17                             |
| Фреймворк        | Spring Boot 2.7.3, Spring WebFlux   |
| База данных      | PostgreSQL 16                       |
| Доступ к БД      | Spring Data R2DBC (реактивный)      |
| Миграции         | Liquibase                           |
| Безопасность     | Spring Security, JWT (JJWT 0.11.5) |
| Маппинг          | MapStruct                           |
| Контейнеризация  | Docker, Docker Compose              |
| Тестирование     | JUnit 5, REST Assured, Allure, Selenium |

---

## Функциональность

| # | Действие                              | Дос��упно                     |
|---|---------------------------------------|------------------------------|
| 1 | Регистрация пользователя              | Всем (дефолтная роль — `ROLE_USER`) |
| 2 | Вход в систему (получение JWT)        | Всем                         |
| 3 | Просмотр списка пользователей         | `ROLE_ADMIN`                 |
| 4 | Просмотр пользователя по ID           | `ROLE_ADMIN`                 |
| 5 | Изменение своих данных                | Всем (кроме смены своей роли)|
| 6 | Изменение данных других пользователей | `ROLE_ADMIN`                 |
| 7 | Проверка доступности роута по роли    | Внутренние сервисы           |

---

## Роли

| Роль           | Описание                                                              |
|----------------|-----------------------------------------------------------------------|
| `ROLE_USER`    | Базовая роль. Может менять только свои данные, не может менять роль   |
| `ROLE_ADMIN`   | Полный доступ: управление всеми пользователями, просмотр списков      |
| `ROLE_ADMIN_R` | Может редактировать только себя (read-restricted admin)               |

> ⚠️ **Ограничение:** имя пользователя (`username`) изменить невозможно — это защищено триггером на уровне БД.

## API

Базовый URL: `http://localhost:8081`

### Публичные эндпоинты

| Метод  | Путь            | Описание                     | Тело запроса                                       |
|--------|-----------------|------------------------------|----------------------------------------------------|
| `GET`  | `/hello`        | Проверка работоспособности   | —                                                  |
| `POST` | `/registration` | Регистрация пользователя     | `{ "username": "...", "password": "...", "role": "ROLE_USER" }` |
| `POST` | `/login`        | Вх��д, получение JWT-токена   | `{ "username": "...", "password": "..." }`         |

### Защищённые эндпоинты (требуют `Authorization: Bearer <token>`)

| Метод  | Путь          | Доступ         | Описание                                      |
|--------|---------------|----------------|-----------------------------------------------|
| `GET`  | `/users`      | `ROLE_ADMIN`   | Список пользователей с пагинацией (`?page=0&size=5`) |
| `GET`  | `/users/{id}` | `ROLE_ADMIN`   | Пользователь по ID                            |
| `PUT`  | `/users/{id}` | Условно        | Изменение пароля и/или роли пользователя      |
